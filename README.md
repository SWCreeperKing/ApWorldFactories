What does the apworld builder do?
- Downloads a google sheet automatically as a CSV
- You use C# code to manipulate the data from the sheet to the underlying world builder
  - Additionaly there is a logic grapher that uses graphvis (it should be optional to use)
  - It can also output data to the game's directory for the mod to use
- It will output autogenerated python code into the given apworld directory
  - All item and location IDs start at 1

The WorldBuilder project is a template to be added to a project as a dependency

ApWorldFactories is all my apworlds and can be used as examples
notable files:
- Runner.cs (for looking at the startup)
- PathConstants.cs (for looking at paths)

examples in the Games folder:
- Poco or Werecleaner (simple examples)
- Atlyss (for looking at how to output locations to use as a string to id)
- Vampire Survivors (for looking at how to read external ddata)
